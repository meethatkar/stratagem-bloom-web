# Eon Media Home Website

## Scope
Build the home page, global header, global footer, and reusable content foundations only. Service and real-estate detail pages will not be built in this phase.

## Implementation
- Create a restrained premium visual system using charcoal, warm white, neutral grey, and a sophisticated copper accent; use editorial typography, sharp geometry, intentional whitespace, and restrained motion.
- Build reusable site primitives for the header, navigation menus, calls to action, section headings, media treatments, metrics, service entries, inquiry form, and footer.
- Build the home page in this order: immersive event-production hero, integrated capabilities editorial composition, four-category services overview, prominent real-estate showcase, credibility and editable metric placeholders, premium inquiry form, and footer.
- Add responsive overlay-to-solid navigation, keyboard-accessible dropdowns, a mobile menu, focus states, reduced-motion handling, and lightweight scroll/reveal effects.
- Use generated, cohesive event and real-estate imagery stored locally with responsive crops, dimensions, eager loading only for the hero, and lazy loading below the fold.
- Implement accessible client-side inquiry validation while keeping submission ready for later email/backend integration.
- Add route-level home metadata, canonical and Open Graph text, Organization/LocalBusiness structured data, semantic landmarks, one H1, and descriptive image alternatives.
- Keep future service and real-estate page content data-driven through reusable configuration types/templates without creating those pages now.

## Verification
- Check the production build and current diagnostics.
- Inspect the live home page at desktop and mobile sizes for layout, navigation, dropdowns, menu behavior, form validation, imagery, and overlaps.
